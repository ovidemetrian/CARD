# Ovi Card — a card you operate

A business card built like the control panels Ovi designs. It's a PWA, installable from the home screen.

**Live:** https://ovidemetrian.github.io/CARD/

- **Scenes** (Smart home · AV system · UI design) open a text to Ovi that's already written. The visitor just presses send.
- **Save my contact** adds Ovi to the phone in one tap (.vcf).
- **Call · Text · Work · Share**
- **Lights** fader dims the room. **Signature** plays a short synthesized sound mark.

Concept & design: Ovi Demetrian · built with Claude

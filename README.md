# Ovi Card — one file, two states

A business card that travels as a single HTML **object** and becomes an installable **PWA** when opened from its home.

**Live:** https://ovidemetrian.github.io/CARD/

- **Object mode:** `index.html` sent as a file works on its own: Call, Text, Email, Save contact (.vcf), Pass it on.
- **App mode:** opened from GitHub Pages, it registers its service worker, can be installed, and works offline.

Edit your details in the `CARD DETAILS` block near the top of the script in `index.html`.
